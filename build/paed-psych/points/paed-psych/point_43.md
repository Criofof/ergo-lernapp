# Grundbegriffe der Pädagogik
## Lernen

**Intentional**
= alle Lernprozesse, die bewusst ausgelöst werden

**Funktional**
= unbeabsichtigt, nicht bewusst wirksam werdende Lernvorgänge
**Fakten:** Intentionales Lernen = bewusst ausgelöste Lernprozesse | Funktionales Lernen = unbeabsichtigte, nicht bewusst wirksam werdende Lernvorgänge
